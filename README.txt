KEY BLOCKER - build with NO Android Studio (GitHub builds it for you)

1. On a computer (or phone browser in desktop mode) go to github.com, sign up/in.
2. Click "+" > New repository. Name it KeyBlocker. Create it.
3. Click "uploading an existing file". Unzip this folder first, then drag in ALL
   its contents (keep the folders, including the hidden .github folder).
   Commit changes.
4. Open the "Actions" tab. Wait ~3-5 minutes for "Build APK" to show a green tick.
5. Click that run, scroll to "Artifacts", download KeyBlocker-apk (a zip).
6. Unzip it, send app-debug.apk to the phone, tap it to install (allow unknown apps).
7. Open Key Blocker > "Open Accessibility settings" > Key Blocker > ON.
8. Test the Recent key. If it still fires, tell me - the app logs key codes.
